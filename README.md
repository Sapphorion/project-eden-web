# Project Eden

A browser game: build a dinosaur park on a volcanic island, then survive it when the systems fail.

**Play:** open `index.html` in a modern desktop browser (Chrome, Edge or Firefox), or visit the GitHub Pages site for this repo.

## How to play
- **Builder:** drag to place paddocks, fences and roads; click to place buildings and dinosaurs. WASD moves the camera, Q/E rotates, the mouse wheel zooms. Esc opens the menu (save, load, sound, exit).
- Raise your park rating with visitors to unlock new buildings and species. Every build adds system strain; once strain passes 22% the park can fail at any moment.
- **Survival:** click to aim with the mouse, left click to fire, right mouse to aim down sights, WASD to move, Shift to sprint. E use, X hide, R reload, 1–6 weapons, H heal, F eat, V energy drink, G hand flare, C crouch, L flashlight, M big map.

Saves are stored in the browser on this site.
